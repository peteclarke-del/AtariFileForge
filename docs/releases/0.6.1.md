# Atari File Forge 0.6.1

## Online Library

The Online Library now includes twelve Atari ST software and driver sources,
including the Atari Document Archive at dev-docs.org. Atarimania results are
checked against their detail pages so available disk-image downloads can be
found and added. Source searches and download handling have been improved for
more useful results across the catalogues.

Software added to a GEMDOS hard disk that cannot be installed automatically is
placed under `INSTALL\STAGE` and marked as staged for installation. Archive
contents that are not disk images are unpacked into staging where supported.

## Folder imports

Folder imports preserve the selected folder and its contents as a directory
tree instead of importing only the files inside it. This also keeps nested
folders together when adding them to an image.

## Upgrading

Install the 0.6.1 package for your system from the About box's **Check for
Application Updates**, or with APT as the
[installation guide](../INSTALLATION.md) describes. Working images,
preferences, profiles and the collection are kept.
