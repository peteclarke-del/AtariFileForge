# Atari File Forge 0.0.0

The initial import of Atari File Forge: the shared workbench, filesystem
services, editors, packaging and tests, retargeted at the Atari ST, Mega ST,
STE, Mega STE, TT030 and Falcon030.

This is a development baseline rather than a release. It establishes the
repository, the Atari naming, the EmuTOS firmware bundle and the
bundled HxCFloppyEmulator converter that the flux workflows rely on. The
release notes for the first usable build will replace this page.
